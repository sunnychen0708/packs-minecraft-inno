# Cat Door Sounds

Minecraft Java 26.2 resource pack.

> Original ZIP name: **Minecraft_Java_26.2_Cat_Meow_and_Door_Open.zip**

## Features

- Replaces normal cat ambient meows with the custom cat sound.
- Keeps the vanilla wooden-door opening sound and adds the custom door-opening sound on top.
- Door closing and other sounds are unchanged.

## Source layout

- `pack.mcmeta` — resource-pack compatibility metadata.
- `assets/minecraft/sounds.json` — sound-event overrides/additions.
- `assets/minecraft/sounds/custom/cat_meow.ogg` — custom cat sound.
- `assets/minecraft/sounds/custom/door_open.ogg` — custom door-opening sound.

Keep this directory unpacked for normal Git development. Build release ZIPs from this directory so `pack.mcmeta` stays at the ZIP root.

## Release naming

Use `cat-door-sounds-v<version>` for release tags.

Example: `cat-door-sounds-v1.0`
