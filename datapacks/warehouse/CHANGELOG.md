# Warehouse Version History

這份文件記錄 `datapacks/warehouse` 已知的版本演進。只記錄 Warehouse 自動分類倉庫本身，不混入其他 datapack / resource pack 的版本。

## v4.0

Minecraft Java 26.3 新物品支援版本。

- 正式加入 Minecraft Java 26.3 新增物品的自動分類。
- 新增共 121 個物品，分類規則由約 1423 條增加到 1544 條。
- 新增內容包含：
  - 楊木與斑駁森林相關物品。
  - 16 色羊毛階梯與羊毛半磚。
  - 16 色坐墊與乾草床。
  - 16 色混凝土階梯與混凝土半磚。
  - 26.3 新版 16 種 Explorer Map。
- 同步更新自動分類、手持物品分類設定、文字搜尋資料與升級 migration。
- 保持 v3.4 的舊世界資料相容性，不重設既有箱子座標、自訂箱名或玩家分類覆寫。
- 26.3 新物品依既有分類邏輯放入：
  - 28 交通運輸：楊木船、儲物箱楊木船。
  - 35 沙岩建材：16 色混凝土階梯、16 色混凝土半磚。
  - 36 原木木材：楊木原木、楊木塊、剝皮楊木原木、剝皮楊木塊、楊木材。
  - 37 木製建材：楊木階梯、半磚、柵欄、柵欄門、按鈕、壓力板、門、地板門、告示牌、懸掛式告示牌、展示架。
  - 41 探索導航：26.3 的 16 種 Explorer Map。
  - 52 羊毛織染：16 色羊毛階梯、16 色羊毛半磚、16 色坐墊、乾草床。
  - 56 林地生態：楊木樹苗、紅／橙／黃楊木樹葉、層孔菇、紅灌木。

### 已知問題

- 文字「查詢功能」對單一關鍵字只保存前 30 個物品 ID。26.3 新物品多數追加在舊清單後方，因此搜尋「階梯」、「半磚」、「羊毛」、「地圖」等結果很多的詞時，部分新物品可能不會出現在文字搜尋結果中。
- 上述問題不影響自動分類與手持物品查詢。
- 部分介面版本文字仍可能顯示 v3.4。

## v3.4

Minecraft Java 26.3 舊世界／舊紀錄相容版本。

- 主要目標是確保從舊版升級到 Minecraft Java 26.3 後，既有倉庫資料可以繼續使用。
- 保留既有註冊箱子的座標與狀態。
- 保留玩家分類覆寫與自訂箱名。
- 保留既有 scoreboard 與相關玩家／系統資料。
- 加入對應的 migration，避免升級時重設重要資料。
- 此版本刻意尚未加入 Minecraft 26.3 新物品分類；26.3 新物品支援延後到 v4.0。

## v3.3

Minecraft Java 26.3 相容性版本。

- 因 Minecraft Java 26.3 更新後，v3.2 無法正常執行，因此開始進行 26.3 相容性修改。
- 調整資料包，使其可以在 Minecraft Java 26.3 正常載入與執行。
- 此階段重點是版本相容，而不是加入 26.3 新物品分類。

## v3.2

介面與操作體驗整理版本。

- 修正 Dialog 在較小畫面可能超出螢幕的問題。
- 將過大的按鈕縮小，包含 3×3 按鈕。
- 統一已註冊／未註冊的顯示方式。
- 修正「目前註冊」頁面的文字與項目描述。
- 移除 GUI 裡的啟動／暫停自動整理按鈕，改由指令控制；自動整理預設開啟。
- 使用說明恢復置中。
- 保留並整理倉庫既有的註冊、查看、命名、分類與查詢操作流程。

## v4.1

未正式製作／發布。

原先規劃修正 v4.0 的兩個問題：

1. 部分 26.3 新物品可以正常自動分類、手持查詢，但無法透過文字「查詢功能」找到。
2. 部分介面仍顯示 v3.4。

後來決定暫不製作 v4.1，因此這不是已發布版本。
