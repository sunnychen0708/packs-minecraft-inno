# Warehouse Version History

這份文件記錄 `datapacks/warehouse` 的版本演進。

| 版本 | 主要更新內容 |
|---|---|
| **v0.1** | 第一個可測核心版本。建立 61 個箱位：00 入口、10～60 六區溢位、54 個主分類箱；匯入約 1423 條預設分類；完成入口箱 → 主箱 → 區域溢位 → 留在入口的安全分類流程；加入基本 Dialog 與箱子註冊。 |
| **v0.2** | 加入銅儲物箱支援，包含不同氧化／上蠟狀態；操作結果盡量改由 Dialog 顯示；改善註冊流程；保留舊版已註冊資料。 |
| **v0.3** | 移除 Dialog 粗體與自訂顏色；嘗試修正關閉按鈕；註冊方式改為 Shift／準星操作；重寫大箱子 A/B 兩半堆疊邏輯，先補既有 stack 再開新 stack；啟動／暫停合成單一按鈕。 |
| **v0.4** | Dialog 改用原生 `after_action: close`；取消 Shift 註冊，改成準星 raycast 自動偵測；完全移除自訂 Advancement 偵測，避免干擾進度系統。 |
| **v0.5** | 修正 raycast 少了 `at @s`，導致偵測位置錯誤的問題；提高 raycast 精度並延長註冊等待時間。 |
| **v0.6** | 註冊方式改回較可靠的右鍵點擊大箱子；新增查看倉庫，能讀取大箱子 A/B 兩半並合併相同物品數量。 |
| **v0.7** | 修正 Dialog 無法直接解析 scoreboard/storage/nbt 動態文字的問題；改用 function macro 產生 inline Dialog，修復註冊數、箱子內容等動態顯示。 |
| **v0.8** | 修正 16 色染色玻璃片錯分到裝飾箱，改至玻璃陶瓦箱；新增遊戲內新增／移除／移動分類規則；規則優先度改為「玩家覆寫 > 預設分類」；移除分類後不會因 `/reload` 自動恢復預設。 |
| **v0.9** | 系統狀態直接顯示於主頁；允許同一實體大箱重複註冊不同編號；新增刪除註冊、讀取箱子、箱子命名；54 個主箱名稱統一四字；加入所有已註冊箱子的背景自動堆疊。 |
| **v0.10** | 修正 v0.9 大量 UI 導航／Macro 問題，包括 Macro function 沒有帶參數、`wh_nav` 太早清零造成刪除註冊與命名無法使用。 |
| **v0.11** | 箱名調整：11 鑽石綠寶、38 其他石頭、55 遠古城市；移除 `11｜名稱` 的直線格式，改成 `11 名稱`；箱子命名改為 Dialog 直接輸入；嘗試加入準星箱名 HUD；修正「回主選單」與右鍵註冊流程。 |
| **v0.12** | 修正 Dialog 命名 SNBT 字串錯誤；修正 `\n` 被直接顯示的換行問題；重寫準星 HUD；另曾提供可選的 Trigger Silent 資源包隱藏「已觸發」訊息。 |
| **v0.13** | 取消準星箱名 HUD；恢復並修正背景自動堆疊；未註冊箱位直接跳過，提高巡檢效率；修正「來源本身已滿 64 就不整理」的問題；箱子管理整理為新增註冊／刪除註冊／命名箱子／目前註冊。 |
| **v1.0** | 第一個正式版。補回六個溢位箱的操作入口；將入口／溢位與主區域箱分開管理；完成正式版靜態完整性檢查。 |
| **v1.1** | 重新整理階層：第一層為入口箱＋區域 1～6；點入口箱後才顯示 00 物品入口、10～60 溢位箱；使用說明加入目前功能；版本標示全面統一。 |
| **v1.2** | 「目前註冊」頁統一為 3×3 主箱顯示；修正文案；移除 Dialog 的啟動／暫停按鈕，改成 `/function warehouse:system/on`、`off`、`toggle`；自動整理預設啟用。 |
| **v1.3** | 由你自行修改了一批介面文字。後續檢查發現這份 ZIP 缺少大量核心檔案，因此之後沒有直接以它作為程式核心，只保留你的 UI 文案修改。 |
| **v1.4** | 加入 `index.html` 的物品查詢功能；支援繁中部分文字、Minecraft ID、分類名稱等搜尋；搜尋會反映玩家目前分類，同時保留預設箱資訊；搜尋索引約 3 萬筆。 |
| **v1.4 Hotfix** | 修正 `warehouse:search/run` 因錯誤 `$` Macro 標記而完全無法載入、顯示「未知函數」的問題。 |
| **v2.0** | 為了避開 Dialog 高權限指令確認頁，曾將查詢改成「書和羽毛筆第一頁輸入關鍵字」的方案。實際操作太麻煩。 |
| **v2.1** | 撤回 v2.0 查詢簿方案，恢復 Dialog 文字輸入搜尋；進行較完整的 Macro、function、Dialog、搜尋索引與分類資料靜態檢查。 |
| **v2.2** | 修正部分「回主選單」仍回到沒有查詢按鈕的舊主頁；分類設定新增打字搜尋物品；正式整合「查詢物品＋分類設定」：搜尋結果可直接點物品進入修改分類；保留手持物品偵測。 |
| **v3.0** | 大幅改善 UI 高度問題；查詢結果與箱子內容加入分頁；查詢結果新增「目前分類箱是否真的有這個物品」狀態；新增修改分類後，自動將舊主箱中的既有庫存背景搬到新箱。 |
| **v3.1** | 查詢結果取消每 4 筆翻頁，改成單欄可捲動列表，最多 30 筆同頁；為避免玩家自訂箱名不同步，查詢結果改成只顯示箱子編號與庫存狀態。 |
| **v3.2** | UI 尺寸統一：查詢結果按鈕縮窄；所有區域 3×3 主箱按鈕統一使用較小尺寸；返回鍵與一般按鈕寬度重新整理，避免超出螢幕。 |
| **v3.3** | Minecraft Java 26.3 初步相容版。Data Pack version 更新到 121.0；修正 26.3 `minecraft:any_block_use` / predicate schema 變更，使資料包能在 26.3 載入。尚未加入 26.3 新物品。 |
| **v3.4** | 26.3 的舊資料相容強化版。重點是確保從 26.2 升級後既有的箱子註冊、玩家自訂箱名、分類覆寫與其他 storage／scoreboard 紀錄能繼續使用；不重新初始化或覆蓋舊資料。這版仍沒有加入 26.3 新物品。 |
| **v4.0** | 正式把 Minecraft 26.3 新增物品加入倉庫分類，沿用既有 54 箱分類邏輯分配新物品，並維持 v3.4 的舊世界資料相容性。 |
| **v4.1** | Hotfix：修正 `warehouse:admin/reset_registrations` 使用不完整的 `data remove storage warehouse:chests`，導致伺服器啟動／reload 時該 function 無法載入的問題；改為只清除 61 個箱位的註冊狀態，保留分類與自訂箱名。 |
| **v4.2** | 修正新世界／升級時搜尋索引初始化一次執行過多指令、觸發 65,536 command-chain 上限的問題。v1.4/v4.0 舊 migration 不再重建已淘汰索引；目前 26.3 索引改為 72 個 shard、每 tick 建立 1 份，完成後才開放搜尋；同時避免物品名稱表重複初始化。 |
| **v4.3** | 新增供其他 datapack 共用的 64-source 材料 API：去重後的庫存查詢、all-or-nothing 扣料、入口箱退款與持久退款 queue；加入玩家可見的 Highlight API，並把物品查詢 → 分類結果 → Highlight 串成同一流程；Warehouse 主頁可進入 Copy/Paste 建築工具。同步加入 v4.3 migration、官方 26.3 runtime regression 與 API/Highlight 靜態驗證。 |
| **v4.4** | Phase 4 Pick：新增 `/trigger pick` 與主頁 Pick 按鈕；準星方塊透過新的 `warehouse:api/resolve_block` 解析成生存物品，再共用 count/take API 從 Warehouse 取出最多一整組。庫存不足一組時取現有數量；不支援的方塊不建立免費物品；物品查詢詳情可直接「取一組」並共用相同扣料路徑。加入 v4.4 非破壞 migration 與 26.3 regression。 |
| **v4.5** | 清理：移除已沒有入口的舊版「讀取箱子」流程（`function/read`、`dialog/read`，其「再試一次」按鈕送出的值也沒有任何處理），玩家可見行為不變；新增只寫入版本 marker 的 v4.4.1 migration。官方 26.3 runtime regression 補上入口箱 → 主箱 → 溢位、合併堆疊、玩家覆寫／移除分類、components 物品、16 堆疊上限、自動堆疊、改分類搬移、搜尋、查看、Highlight 與刪除註冊。修正 Pick 缺貨時訊息直接顯示 `$(item_id)` 而不是物品 ID。 修正：箱子只有 1～8 種物品時「查看倉庫」打不開內容頁（26.3 不接受沒有按鈕的 multi_action Dialog；改成 notice）。三欄的箱子清單按鈕從 150 改成 120 寬，視窗較窄時右邊那排不再超出畫面。選了某個箱子之後的頁面（箱子內容、準備註冊、註冊完成／重複、解除註冊確認／完成／尚未註冊、箱子命名）按「返回／取消」會回到選這個箱子的那一頁（區域頁或入口箱頁），不再跳回箱子管理或查看倉庫首頁。寬度超過 390 的說明文字／輸入框改成 390，頁面不再偏右；入口箱按鈕移到區域 1～6 下方；「回主選單」改開和 G 相同的主畫面（有 Pick 與建築工具），不再出現舊版主畫面。 |
| **v4.6** | 倉庫 chunk 常駐載入：已註冊箱子所在的 chunk 一直保持 forceload（註冊／刪除註冊／重設註冊／載入時重建，每 10 秒補回被其他 datapack 拿掉的；別人原本加的 forceload 不記錄也不移除），沒有人在倉庫附近時背景整理、查詢、Pick、共用材料 API 照常運作。修正查詢物品時倉庫離玩家太遠就把正常箱子顯示成「箱失效」：查詢判斷庫存前，對還沒 forceload 的箱子 chunk 暫時 forceload，讀完立即移除。移除 Warehouse 前先執行 `/function warehouse:chunks/release`。不改世界資料。 |
